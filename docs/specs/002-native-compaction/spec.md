# 跨模型可靠压缩与插件配置

状态：用户已授权实施；版本 2.0.0；2026-10-05。
确认依据：本次用户要求修复指定会话 compact 失败，参考 AgentScope 实现灵活参数，并放在左上角插件配置页；不另设同范围审批。

## 背景与范围
现有会话出现 CONTEXT_WINDOW_EXCEEDED 与 incomplete checkpoint。复现命令 `node test/native-compaction.mjs` 在旧实现失败：volatile getter 配置没有解包，超长请求原样进入适配器。
使用公开 llm/stream、Config volatile、configForms、plugins.bundle.config 和官方压缩事务。移除全局 fetch 劫持与旧设置 API 兼容分支。
只改插件，不改上游或历史事件，不自动清空会话，不重启用户正在使用的桌面应用。

## 交互与策略
左上角插件 → dsh-gateway-compaction → 配置：全局策略、按 provider/model 精确覆盖、窗口/输出/余量、分片与递归合并、最近消息条数及 token 上限、工具参数预处理、重试/超时/调用上限、摘要补充指令、独立摘要模型、自动压缩保留策略。
常规模型、推理模型与本地网关通过宿主模型适配器分流；只选择模型声明支持的 reasoning effort，不注入供应商私有 wire 参数。

## 验收
- Windows 隔离测试：真实 waterfall 路径 + volatile getter + 冻结请求，超窗输入分片后成功；普通对话原样传递。
- 每次内部请求输入+输出+余量不超过估算窗口；超大单消息完整分段；尾部超预算进入摘要，绝不反复塞进每次合并。
- 空输出、截断、溢出、超时、取消、无收敛、调用上限均失败可见，禁止不完整结果伪装 stop。
- 配置范围校验、热更新、保存冲突/失败反馈、公开插槽、主题与窄屏。
- 完成打包与隔离加载；生产安装、真实会话成功和 Ubuntu 实测分别记录，不能混称完成。
